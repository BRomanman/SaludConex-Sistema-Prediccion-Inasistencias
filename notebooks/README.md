# Notebook principal

`SaludConex_Implementacion_Tecnica_Final.ipynb` contiene las etapas de CRISP-DM desarrolladas en el proyecto: exploración, preparación, entrenamiento, evaluación, selección del umbral y exportación de resultados.

- Entorno recomendado: Google Colab.
- Dataset requerido: `data/raw/SaludConex_Datos_Sinteticos_50000.csv`.
- Los CSV incluidos como resultados de referencia se archivan en `outputs/`. Al ejecutar el notebook en Colab, las exportaciones se crean en el directorio de trabajo de la sesión; se pueden descargar o copiar a `outputs/` para actualizar la versión del repositorio.

La copia del repositorio conserva el código, el modelo y los resultados del archivo entregado por el equipo. Para facilitar su lectura en GitHub se reordenaron los encabezados de las Partes 4 y 5 y se fusionó un encabezado Markdown duplicado; no se cambiaron los algoritmos ni las métricas.
