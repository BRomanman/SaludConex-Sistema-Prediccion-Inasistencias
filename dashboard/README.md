# Dashboard de Looker Studio

El dashboard está implementado como prototipo académico y documenta tres páginas:

1. **Resumen General**: 9.443 reservas de prueba, distribución por centro, especialidad, grupo etario, días de anticipación y nivel de riesgo.
2. **Análisis de Reservas de Riesgo**: 5.241 reservas clasificadas como riesgo alto (55,5 %), distribución por centro/especialidad y tabla priorizada por puntaje.
3. **Evaluación del Modelo**: Recall, Precision, F1-score, AUC-ROC, PR-AUC, Accuracy, matriz de confusión y análisis de Recall por centro y grupo etario.

## Evidencias

- `evidencia/SaludConex_Dashboard_LookerStudio.pdf`: exportación de las tres páginas.
- `capturas/`: imágenes individuales para visualización directa desde GitHub.

**Enlace directo a Looker Studio:** pendiente de incorporar por el equipo. No se inventa una URL porque no venía en los archivos entregados.

Los datos cargados al dashboard son archivos CSV estáticos. Las actualizaciones requieren una nueva exportación y recarga/actualización de la fuente, no una sincronización automática en tiempo real.
