# Predicciones para Looker Studio

`SaludConex_Predicciones_Looker.csv`

- Filas: 9.443.
- Columnas: 13.
- Incluye identificador de reserva, centro, especialidad, edad, comuna, fecha y horario de atención, días de anticipación, confirmación del recordatorio, puntaje numérico de riesgo no calibrado, umbral, nivel de riesgo y alerta preventiva.
- No incluye `Resultado_Reserva` ni `Resultado_Real`.

Uso: alimentar la página operativa de análisis de reservas de riesgo. Es una exportación estática; para actualizarla se debe generar un nuevo CSV y actualizar la fuente de Looker Studio.
