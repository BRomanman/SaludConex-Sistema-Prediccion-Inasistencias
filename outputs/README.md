# Resultados exportados

Los dos CSV corresponden a las mismas 9.443 reservas del conjunto de prueba y comparten los mismos `ID_Reserva`.

- `predicciones/`: vista operativa sin el resultado real de la reserva.
- `evaluacion/`: vista retrospectiva que compara predicción y resultado real.

No intercambiar sus usos: el resultado real solo se conoce después de la cita y no debe usarse como variable disponible en una decisión preventiva previa.
