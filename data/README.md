# Datos del proyecto

Todos los registros de este repositorio son **sintéticos y generados con fines académicos**. No contienen historiales clínicos ni datos históricos reales de SaludConex.

El conjunto original contiene 50.000 reservas y 18 variables, con fechas de atención entre 2024-01-01 y 2026-10-31. La descripción de columnas y la distribución del resultado están en `raw/README.md`.
